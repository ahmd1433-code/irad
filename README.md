# إيراد

دليل عربي عملي لبرامج **التسويق بالعمولة** و**الدروب شيبينغ** و**إعادة البيع** على المنصات الكبيرة: أمازون، إيباي، علي إكسبريس، نون، تيك توك شوب، وشبكات مثل أوين وسي جيه.

التطبيق يساعدك تختار النموذج المناسب لرأس مالك وجمهورك، يقارن البرامج، ويقدّر الإيراد قبل التسجيل.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح [http://localhost:43180](http://localhost:43180).

للإنتاج:

```bash
npm run build
npm start
```

## ماذا داخل الدليل

- **البرامج:** تفاصيل العمولة، مدة الارتباط، خطوات البدء، والملاءمة للمنطقة العربية.
- **المسارات:** خطط أسبوعية حسب رأس المال (عمولة، خليج، دروب شيبينغ، فيديو قصير، شبكات).
- **الحاسبة:** تقدير إيراد العمولة أو هامش المتجر أو إعادة البيع.
- **المقارنة:** حتى ثلاثة برامج جنبًا إلى جنب.
- **خطتي:** حفظ البرامج في المتصفح مع حالة التقديم.
- **الوكيل:** يعمل بالنيابة عنك داخل الصلاحيات التي تمنحها (الخطة، الملاحظات، المسار). لا يسجّل في المنصات، لا يدفع، ولا يرفع هوية.

النسب والشروط تتغير. تحقق من الصفحة الرسمية لكل برنامج قبل الاعتماد على أي رقم. المحتوى تعليمي وليس استشارة مالية.
